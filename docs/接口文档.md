# SmartExercise 接口文档

> 前后端分离架构，前端通过 HTTP 调用后端 REST 接口。标注【新增】的接口尚未实现，为规划定义；标注【现有】的接口已实现。前端在接口实现前使用 mock 数据（见前端 `src/mock/`）。

## 1. 通用说明

- **Base URL**：`http://127.0.0.1:8000/api`
- **认证方式**：登录后返回 JWT，除注册/登录外的接口需在请求头携带 `Authorization: Bearer <token>`。
- **权限**：`user` = 登录用户；`admin` = 管理员（`require_admin`）。
- **响应格式**：JSON。成功返回业务数据；失败返回 `{ "detail": "错误信息" }`。
- **状态码**：`200/201` 成功；`400` 参数错误；`401` 未认证；`403` 无权限；`404` 资源不存在；`409` 冲突（如用户名已存在）；`422` 校验失败。

## 2. 认证模块

### 2.1 注册【现有】
`POST /auth/register`

请求体：
```json
{ "username": "zhangsan", "password": "123456" }
```
响应 `201`：
```json
{ "id": 1, "username": "zhangsan" }
```

### 2.2 登录【现有】
`POST /auth/login`

请求体：
```json
{ "username": "zhangsan", "password": "123456" }
```
响应 `200`：
```json
{ "access_token": "<jwt>", "token_type": "bearer" }
```

### 2.3 当前用户信息【新增】
`GET /auth/me` · 权限：`user`

响应 `200`：
```json
{ "id": 1, "username": "zhangsan", "role": "user", "created_at": "2026-10-09T10:00:00" }
```

### 2.4 修改密码【新增】
`PUT /auth/password` · 权限：`user`

请求体：
```json
{ "old_password": "123456", "new_password": "654321" }
```
响应 `200`：
```json
{ "message": "密码已更新" }
```

## 3. 用户模块

### 3.1 更新画像【现有】
`PUT /profile` · 权限：`user`

请求体：
```json
{
  "gender": 0, "age": 25, "height_cm": 175, "weight_kg": 70,
  "goal": "增肌", "experience_level": "初级", "weekly_hours": 6,
  "diet_preference": "高蛋白", "injury": ["无"]
}
```
响应 `200`：同结构画像对象。

### 3.2 获取画像【现有】
`GET /profile` · 权限：`user` · 响应 `200`：画像对象（未录入返回 `404`）。

### 3.3 生成推荐【现有】
`POST /recommend` · 权限：`user`（需已录入画像，否则 `404`）

响应 `200`：
```json
{
  "target_goal": "增肌",
  "weekly_frequency": 4,
  "exercise_plan": [ { "name": "硬拉", "sets": 4, "reps": 8 } ],
  "session_duration_min": 60,
  "intensity_level": "中",
  "training_cycle_weeks": 8,
  "model_version": "rf-v1.0"
}
```

### 3.4 推荐历史【现有】
`GET /recommend/history` · 权限：`user` · 响应 `200`：推荐记录数组（按时间倒序）。

### 3.5 打卡【现有】
`POST /training/records` · 权限：`user`

请求体：
```json
{ "train_date": "2026-10-09", "completion_rate": 0.9, "fatigue_score": 5, "feedback": "适中", "duration_min": 60 }
```
响应 `201`：`{ "id": 1 }`

### 3.6 打卡历史【现有】
`GET /training/records` · 权限：`user` · 响应 `200`：训练记录数组（按日期倒序）。

### 3.7 打卡统计【新增】
`GET /training/stats` · 权限：`user`

响应 `200`：
```json
{ "streak_days": 5, "total_sessions": 23, "week_sessions": 3, "week_completion_avg": 0.87 }
```

### 3.8 记录体重【现有】
`POST /metrics/weight` · 权限：`user`

请求体：
```json
{ "record_date": "2026-10-09", "weight_kg": 68.5 }
```
响应 `201`：`{ "id": 1, "bmi": 22.4 }`

### 3.9 体重历史【新增】
`GET /metrics/weight` · 权限：`user` · 响应 `200`：
```json
[ { "id": 1, "record_date": "2026-10-09", "weight_kg": 68.5, "bmi": 22.4 } ]
```

### 3.10 仪表盘汇总【现有】
`GET /dashboard/summary` · 权限：`user`

响应 `200`：
```json
{
  "training": [ { "date": "2026-10-09", "completion_rate": 0.9, "fatigue_score": 5 } ],
  "weight": [ { "date": "2026-10-09", "weight_kg": 68.5 } ],
  "adjustment": { "available": true, "frequency_delta": 0, "intensity_delta": 0, "advice": "维持当前计划" }
}
```

## 4. 管理员模块

### 4.1 用户列表【现有 + 增强】
`GET /admin/users` · 权限：`admin`

查询参数（新增）：`search`（用户名模糊）、`role`、`page`、`page_size`。

响应 `200`（新增分页结构）：
```json
{
  "items": [ { "id": 1, "username": "zhangsan", "role": "user", "active": true, "created_at": "2026-10-09T10:00:00" } ],
  "total": 1, "page": 1, "page_size": 20
}
```

### 4.2 用户详情【新增】
`GET /admin/users/{id}` · 权限：`admin`

响应 `200`：
```json
{
  "id": 1, "username": "zhangsan", "role": "user", "active": true, "created_at": "2026-10-09T10:00:00",
  "profile": { "age": 25, "goal": "增肌", "height_cm": 175, "weight_kg": 70 },
  "recent_training": [ { "train_date": "2026-10-09", "completion_rate": 0.9 } ],
  "recent_recommendations": [ { "target_goal": "增肌", "created_at": "2026-10-09T10:00:00" } ]
}
```

### 4.3 禁用/启用用户【新增】
`PATCH /admin/users/{id}/status` · 权限：`admin`

请求体：`{ "active": false }` · 响应 `200`：`{ "id": 1, "active": false }`

### 4.4 删除用户【新增】
`DELETE /admin/users/{id}` · 权限：`admin` · 响应 `200`：`{ "message": "已删除" }`

### 4.5 重置密码【新增】
`POST /admin/users/{id}/reset-password` · 权限：`admin`

请求体（可选）：`{ "new_password": "654321" }`（不传则自动生成）· 响应 `200`：`{ "username": "zhangsan", "new_password": "654321" }`

### 4.6 数据总览【新增】
`GET /admin/overview` · 权限：`admin`

响应 `200`：
```json
{
  "kpi": { "total_users": 128, "new_users_today": 3, "total_recommendations": 512, "total_sessions": 1024, "active_users_week": 45 },
  "user_growth": [ { "date": "2026-10-01", "count": 5 } ],
  "goal_distribution": [ { "goal": "增肌", "count": 40 } ],
  "completion_distribution": [ { "range": "80-100%", "count": 60 } ]
}
```

### 4.7 推荐记录列表【新增】
`GET /admin/recommendations` · 权限：`admin`

查询参数：`user_id`（可选）、`page`、`page_size`。

响应 `200`：
```json
{ "items": [ { "id": 1, "user_id": 1, "username": "zhangsan", "target_goal": "增肌", "created_at": "2026-10-09T10:00:00" } ], "total": 1 }
```

### 4.8 训练数据统计【新增】
`GET /admin/training` · 权限：`admin`

响应 `200`：
```json
{ "total_sessions": 1024, "avg_completion": 0.78, "avg_fatigue": 5.2, "completion_distribution": [ { "range": "80-100%", "count": 60 } ] }
```

### 4.9 动作库列表【新增】
`GET /admin/exercises` · 权限：`admin`

查询参数：`muscle_group`、`exercise_type`。

响应 `200`：`[ { "id": 1, "name": "硬拉", "muscle_group": "背", "exercise_type": "力量" } ]`

### 4.10 新增动作【新增】
`POST /admin/exercises` · 权限：`admin`

请求体：`{ "name": "硬拉", "muscle_group": "背", "exercise_type": "力量" }` · 响应 `201`：动作对象。

### 4.11 编辑动作【新增】
`PUT /admin/exercises/{id}` · 权限：`admin` · 请求体同 4.10 · 响应 `200`：动作对象。

### 4.12 删除动作【新增】
`DELETE /admin/exercises/{id}` · 权限：`admin` · 响应 `200`：`{ "message": "已删除" }`

### 4.13 模板列表【新增】
`GET /admin/templates` · 权限：`admin`

查询参数：`goal`、`intensity_level`。

响应 `200`：
```json
[ { "id": 1, "goal": "增肌", "intensity_level": "中", "exercise_ids": [1,2,3], "sets": 4, "reps": 8, "session_duration_min": 60, "weekly_frequency": 4, "training_cycle_weeks": 8 } ]
```

### 4.14 新增模板【新增】
`POST /admin/templates` · 权限：`admin` · 请求体同 4.13（不含 `id`）· 响应 `201`：模板对象。

### 4.15 编辑模板【新增】
`PUT /admin/templates/{id}` · 权限：`admin` · 请求体同 4.13 · 响应 `200`：模板对象。

### 4.16 删除模板【新增】
`DELETE /admin/templates/{id}` · 权限：`admin` · 响应 `200`：`{ "message": "已删除" }`

### 4.17 模型信息【现有】
`GET /admin/model` · 权限：`admin`

响应 `200`：
```json
{ "loaded": true, "best_params": { "max_depth": 10, "n_estimators": 50 }, "metrics": { "target_goal": { "accuracy": 1.0, "f1": 1.0 } } }
```
